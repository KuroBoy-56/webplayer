🌐 Dominio propio para la web player con un Worker de Cloudflare

Tus clientes entran por un dominio nuevo (el tuyo o el de un distribuidor). El dominio original de la web player responde 403 Forbidden y nunca se ve. El video no pasa por Cloudflare.

Dónde va cada dominio (en toda la guía están en amarillo y azul, en grande):
  • TUDOMINIO.COM = el dominio nuevo que compras (por ejemplo webplayer-mpx.com). Va solo en Cloudflare (paso 1 y paso 5). No va en el código del Worker.
  • WEB-ORIGINAL.COM = la dirección actual de tu web player en Hostinger (hoy webplayer.mpx.work). Va en la variable ORIGIN del Worker (paso 4).

1. Cómo funciona

  • El cliente escribe TUDOMINIO.COM. Cloudflare ejecuta tu Worker, que abre por dentro la web player original y le manda el secreto.
  • La web player solo atiende si el secreto es correcto. Toma el dominio que ve el cliente y su IP real, así el login, las cookies y el freno de intentos funcionan igual que hoy.
  • Quien entre directo a WEB-ORIGINAL.COM recibe 403 Forbidden.
  • El video no pasa por Cloudflare: va de la VPS / VDS al navegador, como ahora.

2. Antes de empezar

  • ✅ La web player del hosting actualizada con el último webplayer.zip (trae includes/edge.php).
  • ✅ La web player original abre bien hoy por https (SSL activo en Hostinger).
  • ✅ Tu VPS / VDS con el motor actualizado y su certificado (el video de la web en https va por ella).
  • ✅ Una cuenta gratis en cloudflare.com. El plan gratis alcanza (100.000 visitas de páginas por día).

Mientras no hagas el paso 6, nada cambia: la web funciona exactamente igual que hoy.

PASO 1

Comprar el dominio y pasarlo a Cloudflare

  1. Compra TUDOMINIO.COM donde quieras (Hostinger, Namecheap, Cloudflare…).
  2. En Cloudflare › Add a domain (Agregar un dominio) › escribe TUDOMINIO.COM › plan Free.
  3. Cloudflare te da 2 nameservers (por ejemplo ana.ns.cloudflare.com). En la página donde compraste el dominio, cambia los nameservers por esos dos.
  4. Espera el correo «Your domain is now active» (de minutos a unas horas).
  5. En Cloudflare › TUDOMINIO.COM › SSL/TLS › Edge Certificates: activa Always Use HTTPS.

No hace falta crear registros DNS para la web: el paso 5 los crea solo.

PASO 2

Crear el secreto

Es una contraseña larga que solo conocen el Worker y tu web player. En tu PC abre PowerShell y pega esta línea:

PowerShell (tu PC)
-join ((48..57)+(65..90)+(97..122) | Get-Random -Count 48 | % {[char]$_})

Te sale algo como k3J9xQ2… (48 letras y números). Guárdalo en un bloc de notas: lo vas a pegar en el paso 4 y en el paso 6.

El secreto debe tener mínimo 32 letras y números (sin espacios). Uno distinto por cada dominio.
PASO 3

Crear el Worker y pegar el código

  1. Cloudflare › menú izquierdo Workers & Pages (Compute › Workers) › Create › Create Worker (o «Start with Hello World!»).
  2. Nombre: mpx-web (para un distribuidor: mpx-web-distA…). Pulsa Deploy.
  3. Pulsa Edit code. Borra todo lo que hay y pega este código completo (es el archivo cloudflare/edge-worker.js de la web player):
Cloudflare › Worker › Edit code (no cambies nada del código: el dominio NO va aquí)
// MPX Player · Worker de Cloudflare para un dominio propio de la web player.
// Variables (Settings › Variables and Secrets): ORIGIN (Text) y EDGE_KEY (Secret).
export default {
  async fetch(request, env) {
    const origin = String(env.ORIGIN || '').trim().replace(/\/+$/, '');
    const key = String(env.EDGE_KEY || '').trim();
    if (!/^https?:\/\/[^/]+$/i.test(origin) || key.length < 32) {
      return new Response('Worker sin configurar: falta ORIGIN o EDGE_KEY (ver GUIA-WORKER.html)', { status: 500 });
    }
    const seen = new URL(request.url);
    const to = new URL(seen.pathname + seen.search, origin + '/');
    const headers = new Headers(request.headers);
    headers.set('X-MPX-Edge', key);
    headers.set('X-Forwarded-Host', seen.host);
    headers.set('X-Forwarded-Proto', seen.protocol.replace(':', ''));
    headers.set('X-MPX-Client-IP', request.headers.get('CF-Connecting-IP') || '');
    const init = { method: request.method, headers, redirect: 'manual' };
    if (request.method !== 'GET' && request.method !== 'HEAD') init.body = request.body;
    let res;
    try {
      res = await fetch(to.toString(), init);
    } catch (e) {
      return new Response('No se pudo abrir la web player original (' + origin + ')', { status: 502 });
    }
    const loc = res.headers.get('Location');
    if (loc) {
      try {
        const l = new URL(loc, to);
        if (l.host === new URL(origin).host) {
          l.protocol = seen.protocol;
          l.host = seen.host;
          res = new Response(res.body, res);
          res.headers.set('Location', l.toString());
        }
      } catch (e) { }
    }
    return res;
  },
};
  1. Pulsa Deploy (arriba a la derecha).
PASO 4

Variables del Worker: ORIGIN y EDGE_KEY

Worker mpx-web › Settings › Variables and Secrets › Add:

SecretEDGE_KEYel secreto del paso 2

Pulsa Deploy / Save.

Escribe ORIGIN y EDGE_KEY exactamente así, en mayúsculas.
PASO 5

Conectar TUDOMINIO.COM al Worker

  1. Worker mpx-web › Settings › Domains & Routes › Add › Custom domain.
  2. Escribe TUDOMINIO.COM › Add domain. Cloudflare crea el registro DNS y el certificado solo (unos minutos).
  3. Si también quieres www.TUDOMINIO.COM, repite con ese nombre.

Para una carpeta o un subdominio (por ejemplo tv.TUDOMINIO.COM) es igual: escribe ese nombre.

PASO 6

Poner el secreto en la web player (primero en modo prueba)

  1. Hostinger › Administrador de archivos › carpeta de la web player › includes/panel_secret.php › Editar.
  2. Ya tiene la línea 'master_key_hex' => '…',. Debajo de ella, antes del ]; final, pega:
Hostinger › web player › includes/panel_secret.php
    'edge_keys' => [
        'PEGA_AQUI_EL_SECRETO_DEL_PASO_2' => '',
    ],
    'edge_block' => false,

Cambia PEGA_AQUI_EL_SECRETO_DEL_PASO_2 por tu secreto (dentro de las comillas). Guarda. El archivo queda así:

<?php
return [
    'master_key_hex' => '…(la que ya tenías, no la toques)…',
    'edge_keys' => [
        'k3J9xQ2…tu secreto…' => '',
    ],
    'edge_block' => false,
];
  • '' a la derecha del secreto = en ese dominio el cliente escribe su número de distribuidor o pulsa Omitir, como hoy.
  • 'edge_block' => false = modo prueba: el dominio original todavía abre. Así pruebas sin riesgo.
PASO 7

Probar

  1. Abre https://TUDOMINIO.COM: debe salir el inicio de sesión de la web player, con candado 🔒.
  2. Inicia sesión, abre una película, un capítulo y un canal en vivo: deben reproducir igual que en el dominio original.
  3. Cierra sesión y vuelve a entrar. Prueba también desde el celular.

Si algo falla, mira Errores comunes. Mientras estés en modo prueba, tus clientes siguen entrando por el dominio original sin problema.

PASO 8

Cerrar el dominio original (403 Forbidden)

Cuando todo funcione por TUDOMINIO.COM, en includes/panel_secret.php cambia:

    'edge_block' => true,

(o borra esa línea: sin ella también bloquea). Guarda y abre https://WEB-ORIGINAL.COM: debe salir 403 Forbidden. Por TUDOMINIO.COM todo sigue funcionando.

Avisa a tus clientes de la dirección nueva antes de este paso: los que guardaron el dominio original verán 403.

El panel puede seguir hablando con la web player (botones del motor de la web en Guía EPG): esa conexión va firmada con la llave maestra y no se bloquea.

Dominios de los distribuidores (todos los que quieras)

Sí: puedes hacer lo mismo con cada distribuidor que compre su dominio, sin límite. Cada dominio lleva su propio Worker y su propio secreto. En panel_secret.php, a la derecha de su secreto va el número de 6 dígitos de ese distribuidor. Así su web queda fija en él: sus clientes no ven la pantalla «Número de distribuidor» ni el enlace «Cambiar distribuidor». Ven su marca (nombre, logo y colores) como siempre.

Opción A · El dominio del distribuidor en TU Cloudflare (recomendada)

  1. El distribuidor compra su dominio y cambia sus nameservers a los de tu cuenta de Cloudflare (paso 1 con su dominio).
  2. Creas un secreto nuevo (paso 2).
  3. Creas un Worker nuevo, por ejemplo mpx-web-a (paso 3), con el mismo código.
  4. Variables (paso 4): ORIGIN = https://WEB-ORIGINAL.COM (la misma de siempre) y EDGE_KEY = su secreto nuevo.
  5. Custom domain (paso 5): DOMINIO-DEL-DISTRIBUIDOR.COM.
  6. En panel_secret.php agrega una línea más dentro de 'edge_keys', con su número:
    'edge_keys' => [
        'secreto-de-tu-dominio…' => '',
        'secreto-del-distribuidor-A…' => '123456',
        'secreto-del-distribuidor-B…' => '654321',
    ],

Opción B · El distribuidor con su propia cuenta de Cloudflare

Él hace los pasos 1, 3, 4 y 5 en su cuenta. Tú le das solo su secreto (paso 2) y la dirección ORIGIN, y agregas su línea en panel_secret.php. Nunca le des la llave maestra ni otro secreto. Para quitarle el acceso, borra su línea: su dominio da 403 al instante.

No hay límite de dominios. El plan gratis de Cloudflare permite hasta 100 Workers por cuenta y 100.000 visitas de páginas por día sumando todos (el video no cuenta porque no pasa por Cloudflare). Si se te queda corto, el plan Workers Paid cuesta 5 USD al mes.

¿Hace falta un .htaccess?

No. Basta con panel_secret.php: todas las páginas de la web player (login, inicio, fichas, reproductor, api.php, carátulas…) pasan por PHP y responden 403 sin el secreto. Solo los archivos fijos públicos (estilos, scripts, el logo) se pueden seguir abriendo sueltos por el dominio original, pero no sirven para nada sin las páginas. El .htaccess que ya trae la web no se toca.

Volver atrás / si te quedas sin acceso

  • Quitarlo todo: borra las líneas 'edge_keys' y 'edge_block' de panel_secret.php: la web vuelve a funcionar exactamente como antes por el dominio original.
  • Abrir otra vez el original sin quitar los Workers: pon 'edge_block' => false,.
  • Siempre se edita desde el Administrador de archivos de Hostinger, que no depende de la web player.
